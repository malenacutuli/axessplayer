# Axessplayer monorepo

Wave 0 scaffold generated by the W0 orchestrator. Contracts live in `contracts/` (version 0.3.0, candidate). Do not declare contracts frozen or tag `contracts-v0.3.0` until the three open sign-offs clear: PF-6, PF-8, PF-10 (see contracts/PRE_FREEZE_CHECKLIST.md). No em dashes.

## Setup
```
pnpm install
pnpm gen                 # generate typed clients from the OpenAPI specs
pnpm contracts:validate  # lint the OpenAPI specs
pnpm typecheck && pnpm lint && pnpm test
```

## Layout
apps/ (mobile, web, studio, marketing) · services/ (content, economy, decision, manifest, generation, trust, experiment) · packages/ (contracts, player-sdk, analytics-sdk, ui).

Each package has a CLAUDE.md scoping its owning workstream. Start a workstream agent in its own git worktree with the matching brief in AGENTS/.
